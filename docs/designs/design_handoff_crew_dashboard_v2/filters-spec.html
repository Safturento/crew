Implementation notes. Reference CSS uses the existing .app--vw-mobile / .app--vw-vertical modifiers (set by the prototype's viewport tweak) to drive the wrap. Production should use a container query on the drawer (@container (max-width: 768px)) so the controls bar reflows whether the drawer is opened over a wide list or as a full-screen sheet. On mobile the popover anchors to the trigger but caps at calc(100vw - 48px) so it never clips the sheet edge.
