## Decisions

- **Frontmatter skill-config moves to `.agents/design-system.md` frontmatter.** The `design-with-figma` skill (`~/.claude/skills/`) reads URLs + sample data from these fields, so they need a stable home. The validator only enforces required keys; extra keys are permitted.
- **Kept as a single file, not split into `.agents/design-system/`.** The `.agents/README.md` meta-rule allows splitting once a topic crosses ~200 lines with natural subdivisions. Result is right around that threshold but reads coherently top-to-bottom; defer the split unless a future addition makes it warranted.
- **Out-of-date Pill consolidation noted but not adopted as canonical.** Memory captures a 2026-05-12 Figma-side consolidation into a unified `Pill` component (192 variants); the code still ships separate `StateBadge` / `CountBadge` / shadcn `Button`. The rules doc reflects the **code's** current shape; the Pill consolidation lives in rationale as the Figma-side evolution.
