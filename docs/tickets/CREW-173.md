# CREW-173 — figma-snapshot: committed artifact + figma-snapshot-refresh skill

Jira: https://safturento.atlassian.net/browse/CREW-173

## Goal

Stop generating the Figma snapshot per-dispatch. Make it a committed artifact,
regenerated by an interactive skill. This branch ships **PR A** (autonomous): the
CLI / config / doc code.

## Scope (PR A — this branch)

- Remove `runPreDispatchFigmaSnapshot` + the `run.ts` pre-dispatch block.
- Delete the `plugin-api-enrichment.ts` subprocess; `crew figma-snapshot` is now
  a REST-only export.
- `emitSnapshot` writes `<snapshot_path>/meta.json` (`figmaFileVersion` + `capturedAt`).
- Add `crew figma-snapshot --check` — compares committed `meta.json` to the live
  Figma file version, exits non-zero when stale.
- Remove `skip_snapshot` from the config schema.
- Un-gitignore `.crew/figma-snapshot/`.
- Update `.agents/dispatch.md` + `docs/visual-fidelity-setup.md`.

PR B (interactive — the `figma-snapshot-refresh` skill + first committed snapshot)
is a separate follow-on session, not this branch.

## Relevant files

- `packages/cli/src/commands/figma-snapshot.ts` — the command; REST-only + `--check`.
- `packages/cli/src/lib/figma-snapshot/{client,emit}.ts` — `version`, `getFileMeta`, `meta.json`.
- `packages/cli/src/commands/run.ts`, `packages/cli/src/lib/run/figma-snapshot-step.ts` — pre-dispatch removal.
- `packages/shared/src/config/schema.ts` — drop `skip_snapshot`.

## Decisions

- **Version stored in a `meta.json` sidecar, not `index.json`** — `visual-fidelity-check`
  iterates `index.json` keys as node IDs; a top-level field would break that.
- **`enrichment-prompt.ts` left orphaned** — PR B relocates its script into the skill
  and deletes it. An exported const with no importer is harmless.
